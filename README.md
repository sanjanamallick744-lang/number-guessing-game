# 🎯 Number Guessing Game in C++

A simple **Number Guessing Game** developed using **C++**. The computer randomly selects a number between **1 and 100**, and the player has to guess the number. After each guess, the game provides a hint whether the guessed number is too high or too low.

## 📌 Features

* 🎲 Generates a random number between 1 and 100
* 🔢 Takes guesses from the player
* 💡 Gives hints:

  * **Too High**
  * **Too Low**
* 🏆 Displays a congratulatory message when the correct number is guessed
* 📊 Counts the total number of attempts
* 💻 Simple console-based interface

## 🛠️ Technologies Used

* **C++**
* **Dev-C++**
* Standard C++ libraries:

  * `iostream`
  * `cstdlib`
  * `ctime`

## 🎮 How to Play

1. Run the program in **Dev-C++**.
2. The computer will randomly select a number between **1 and 100**.
3. Enter your guess.
4. Follow the hint provided by the game.
5. Keep guessing until you find the correct number.
6. The game will display the number of attempts taken.
